# Việt Dũng - Daezal | Portfolio

Personal portfolio ready for https://imnotdaezal.github.io/.

## Publish using GitHub's website

1. Create a PUBLIC repository named exactly `imnotdaezal.github.io` on your `imnotdaezal` account. Add a README when creating it so that the main branch exists.
2. Extract this ZIP on your computer.
3. In the repository choose Add file > Upload files. Drag in `index.html`, the complete `assets` folder and this README.md, then commit to main. If your file picker hides `.nojekyll`, create that empty file with Add file > Create new file after uploading.
4. IMPORTANT: Upload the extracted contents, not this ZIP or an outer folder. `index.html` and `assets` must be at the repository root.
5. Open Settings > Pages > Build and deployment.
6. Select Deploy from a branch, branch main, folder /(root), then Save.
7. Check the Pages deployment in Actions. When successful, open https://imnotdaezal.github.io/.

## Editing

All HTML, CSS and JavaScript are in index.html. Photos are in assets/. No npm install or build step is required. Keep asset names unchanged unless you update references in index.html too.

## Music

Uses the official Spotify iframe API and attempts playback when ready. Browsers may block autoplay and Spotify may only provide a preview. Full-song playback cannot be guaranteed by this website. The Open in Spotify link remains available.
